# Freshness check for candidate gaps

For each candidate, search its claimed missing capability using exact language, synonyms, neighboring-field language, and the nearest method name. Search recent arXiv, current venue programs, cited-by pages, and relevant author/lab pages. Save queries, retrieval date, closest matches, and why each match closes, narrows, or does not address the gap.

Do not retain a candidate marked `unverified` or `likely_closed`. If a recent preprint overlaps, report the overlap even without peer review and reduce the novelty claim accordingly.
