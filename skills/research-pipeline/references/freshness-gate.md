# Current gap verification

Run this gate immediately before accepting a research gap.

1. Record the execution date and literature cutoff date.
2. Search the exact claimed capability, its synonyms, the nearest method family, and the application-specific formulation.
3. Search the latest 3-6 months of arXiv and current or forthcoming programs of relevant venues.
4. Inspect cited-by pages and author/lab follow-ups for the nearest papers.
5. Record counterexamples, ambiguous matches, inaccessible sources, and searches returning no useful results.
6. Compare each close match by problem, input/output, assumptions, method, data, evaluation, and contribution.

Label the result `open`, `partially_open`, `likely_closed`, or `unverified`. Only `open` and a precisely narrowed `partially_open` gap may reach idea selection. Absence from model memory or one scholarly index is never proof that a gap is open.
